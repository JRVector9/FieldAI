상세 기록: `document_structure.json`.

## 2. JSON Schema·합성 예제

JSON Schema 3개와 정상 예제 3개의 문법·검증을 실행했다. 다음 7가지 잘못된 입력을 거부하는지 검사했다.

1. 무인증 고객 연락처를 인증 완료로 표기.
2. 메타데이터 이벤트에 고객 전화번호 포함.
3. 외부 AI 작업으로 예약 확정 실행을 요청.
4. 정수가 아닌 revision.
5. 시간표 요청에서 시작·종료 누락.
6. 고객 제출 동의 참조 누락.
7. 비공개 사실을 공개 지식 스냅샷으로 전달.

이 검사는 스키마 수준의 허용 필드를 확인한다. 실제 인증, 개인정보 감지, 서버 권한, 서명·재전송 방지, 동시성, 필드 간 업무 의미와 외부 실행의 안전성을 입증하지 않는다. 예제의 해시·ID·연락처는 검증용 합성값이며 실제 발송·인증에 사용할 수 없다.

상세 기록: `schema_check.json` 및 `contracts/CONTRACT_NOTES.md`.

## 3. HTML 보고서

Playwright와 컨테이너의 Chromium을 사용해 읽기용 보고서를 검사했다. 해당 환경의 로컬 파일 접근 제약으로 HTML 원문을 `page.set_content`로 로드했다. 파일 링크를 실제 사용자 앱에서 클릭하거나 서비스에 배포한 테스트는 아니다.

| 화면 너비 | 문서 가로 넘침 | 14px 미만 표시 글자 | 스크립트 오류 |
|---|---|---|---|
| 320px | 없음 | 없음 | 없음 |
| 390px | 없음 | 없음 | 없음 |
| 768px | 없음 | 없음 | 없음 |
| 1440px | 없음 | 없음 | 없음 |

390px에서 목차 열기·목차 검색·검색된 항목 이동·메뉴 닫힘을 검사했다. 긴 표는 표 컨테이너 내부 가로 스크롤로 제공하며 페이지 전체 가로 넘침과 구분했다. 대표 화면 및 공식 연동 계약 화면의 스크린샷을 확인했다.

상세 기록: `report_browser.json`, `report_*.png`, `integration_*.png`.

## 4. 실행하지 않은 검수

AP/Field 운영 서버·실제 OAuth 승인·설치 SDK·외부 iframe·고객 접수·결제·알림·예약 확정·DB 격리·복구·160개 서비스 인수 테스트는 실행하지 않았다. iOS/Safari·Android 실기기·Firefox·스크린리더·인쇄 결과·전체 HTML 문장의 육안 전수 검수도 실시하지 않았다. 외부 공급사 계약, 카카오 템플릿, PG, DNS/TLS, 법적 고지 승인 상태는 이 문서 패키지의 검사로 대체할 수 없다.

## 5. 재실행 도구

`tools/check_package.py`, `tools/build_contract_examples.py`, `tools/check_report.py`는 이 문서 패키지의 검사·생성용이다. Python 및 스크립트가 사용하는 jsonschema / markdown-it-py / Playwright·Chromium 환경이 필요하다. `AGENTS.md`에 정한 pnpm 명령은 이후 개발 리포지터리에 구현할 계약이며 이 문서 ZIP 자체가 실행 가능한 서비스 저장소라는 뜻이 아니다.
